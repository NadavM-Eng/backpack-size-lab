# Aer Travel Pack 4 28L: measurements taken from the photos

Published: 48.9 H × 32.4 W × 20.3 D cm, 28 L, 16" laptop. Silhouettes were measured by thresholding
the light-grey studio background (#f2f2f2, |Δ| > 40) and reading row runs (480 px Aer studio shots).
"Viewer's left" = seen from the front = −X in the model (front = −Y, back = +Y in Blender).

## Scale and what the published numbers include
- back.jpg: top (handle) y 45 → base y 431 = 386 px; body width 111–369 = 258 px.
  386 px / 48.9 cm = 7.89 px/cm → width 258 / 7.89 = **32.7 cm** (published 32.4 ✓).
  So **H = 48.9 includes the top handle**.
- side_right.jpg: handle top y 57 → base y 430 = 373 px → **7.63 px/cm**. Body top (top surface,
  handle excluded) y ≈ 71 → **body height ≈ 47.0 cm**; the padded handle adds ≈ **1.9 cm**.
- side_right body depth (front face x 115 → back face x 278) = 163 px = **21.4 cm** at the fullest
  (0.75–0.85 H), straps excluded; with straps the studio side view spans 115 → 394 = 36.6 cm.
  → **D = 20.3 is the body depth without straps** (photo reads ~5 % deeper: stuffed sample /
  mesh padding), so the model scales the measured profile by 0.944.
- NN_28L_vs_35L_*: the 28 L is the shorter/narrower bag; proportions of the 28 L there match
  the studio shots (H/W ≈ 1.5).
